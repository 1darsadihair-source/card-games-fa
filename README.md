# چهاربرگ | بازی‌های کارتی فارسی

نسخه‌ی اولیه‌ی رابط کاربری برای پروژه‌ی بازی‌های کارتی فارسی با React و Vite.

## اجرا
```bash
npm install
npm run dev
```

## وضعیت فعلی
- صفحه‌ی معرفی فارسی و راست‌چین
- انتخاب بین حکم، شلم و پاسور
- میز بازی آزمایشی و تعامل اولیه با کارت‌ها
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

**توجه:** این نسخه نمونه‌ی اولیه است؛ قوانین کامل و رسمی هر بازی، بازی آنلاین، حساب کاربری، ذخیره‌سازی و تبلیغات هنوز پیاده‌سازی نشده‌اند.
